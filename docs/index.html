Premiere-grade. Zero price.

Every tool here runs on your machine. Import, cut, grade, mix, export — the whole professional loop, with the keyboard workflow editors already have in their hands.

🎬

Non-linear timeline

Multi-track video & audio, blade, ripple-delete, detach audio, nested sequences, snapping, markers — the editing grammar professionals speak.

📈

Keyframed effects

Bezier easing on every property. Adjustment layers grade whole stacks. Chroma key, blur, noise, sharpen, saturation, color wheels, crop & transform.

🎚️

Audio, mixed properly

Per-clip gain, fades with curve handles, solo/mute per track, master live meters. The sound of your cut is not an afterthought.

⚙️

FFmpeg render engine

Bundled pro export — H.264, HEVC, ProRes, WebM, plus WAV/MP3/GIF. Hardware-aware fallback chain means you always get a file out.

⚡

GPU-accelerated preview

WebGL compositor with automatic CPU fallback. Scrub and play your graded timeline in real time on ordinary hardware.

🧠

Optional local AI tools

Whisper transcription and whisper-cut — entirely offline when you drop a model in. AI ambitious, force point.

From zero to a clean cut in minutes.

No tutorials required, no signup wall. Three steps and you're editing.

1

Download the installer

One 99 MB file from Releases. Everything's inside — Electron runtime, FFmpeg engine, the app.

2

Run it

Windows may show SmartScreen (we're a new open project, not yet signed) — click More info → Run anyway. Pick a folder, done. Start Menu + Desktop shortcuts included.

3

Cut & export

Drop media onto the timeline, Ctrl+K to blade, keyframe a zoom, then Ctrl+Shift+E for Pro Export. Mp4 out, straight to your disk.

Questions, answered.

The fine print — there isn't any. But here it is anyway.

Is it actually free? What's the catch?

Truly free — MIT licensed, no premium tier, no trial timer, no watermark. The catch is only this: it's young software built in the open, and your issue reports make it sharper. That's the exchange.

Does it send my videos anywhere?

No. ApolloCut is 100% local — no accounts, no telemetry, no network calls in the editor code. Drop an NDA project in there; it never leaves your disk.

Why does Windows warn me when I install?

Because an unsigned open-source exe is "unknown" to SmartScreen. Click More info → Run anyway. The source is public — you can build the exact same installer yourself with npm run dist and compare.

How do I update later?

Run the new installer over the old one — settings and projects survive. New releases are built automatically by GitHub Actions every time a v* tag is pushed.
